# 📋 Comprehensive Analysis Plan: Trial Size Impact on Long-Term Customer Value

**作成日**: 2026年1月30日  
**目的**: 多角的にトライアル時サイズがもたらす顧客価値を評価し、大きいサイズ購入者の真のロイヤリティを解明する

---

## 🎯 Analysis Objectives

現在の分析では「大きいサイズのリピート率が低い」ように見えるが、これは：

1. **消費期間の違い**: 大きいサイズは消費に時間がかかり、短期間では不利
2. **観測期間の問題**: 現在の2-3ヶ月では大サイズの真のリピートを捉えられない

**仮説**: 大きいサイズでトライアルした顧客は、実際にはより高いロイヤリティを持っている

---

## 📊 Phase 1: Extended Repeat Period Analysis（必須）

### 1.1 6ヶ月リピート率の再計算

**実施内容:**

- 現在のリピート観測期間を**6ヶ月**に延長
- トライアル終了日から6ヶ月以内のリピート購入を捕捉
- 個別サイズごとのリピート率を再計算

**データフラグ（2026年1月30日時点）:**

```
⚠️ 観測期間不足（6ヶ月未満）:
- Anakin (All): 12/1→1/30 = 約2ヶ月
- Rapunzel (All): 10/31→1/30 = 約3ヶ月
- Nanox One: 10/24→1/30 = 約3ヶ月
- Bold Gel (Liquid): 10/31→1/30 = 約3ヶ月

✅ 完全比較可能（6ヶ月以上）:
- Ariel Gel (Liquid): 4/17→10/17+ = 6ヶ月+
- Attack Antibacterial EX: 8/4→2/4+ = 6ヶ月+
- Srixon, Srixon Boost, Yoda, Moana, Cinderella, Snowwhite
```

**期待される結果:**

- 大きいサイズのリピート率が時間とともに上昇
- 小さいサイズは早期にリピート率が頭打ち

---

## 📊 Phase 2: Time-to-Repeat Analysis（消費速度）

### 2.1 サイズ別「リピートまでの平均日数」

**測定指標:**

- トライアル初回購入日 → 初回リピート購入日までの日数
- サイズごとの中央値・平均値・分布

**分析例:**

```
詰替ﾃﾗｼﾞｬﾝﾎﾞ: 平均 95日, 中央値 87日
詰替ﾒｶﾞｼﾞｬﾝﾎﾞ: 平均 65日, 中央値 58日
本体通常: 平均 42日, 中央値 38日
```

**仮説検証:**

- 大きいサイズは消費期間が長い = リピート出現が遅い
- この「遅さ」は問題ではなく、長期使用の証拠

### 2.2 比較可能期間での挙動分析

**実施内容:**

- トライアル後「最初の2ヶ月」のみで全商品を比較
- 各サイズの「2ヶ月時点リピート率」を算出
- 6ヶ月対応商品は「2ヶ月時点」と「6ヶ月時点」の差分も表示

**表示形式:**

```
商品A (6ヶ月データあり): 2ヶ月 30% → 6ヶ月 45% (+15pt)
商品B (2ヶ月のみ): 2ヶ月 32% → (観測期間不足)
```

## 📊 Phase 3: Retention & Engagement Analysis（定着率）

### 3.1 定着率の定義と測定

**Option A: N回以上リピート率**

```python
# リピート期間内に2回以上購入 = 定着
定着率 = リピート2回以上の人数 / トライアル人数
```

**Option B: M週連続購入率**

```python
# トライアル後、X週間のうちY週以上購入
# 例: 12週のうち3週以上購入した人の割合
```

**Option C: 最終購入日の新しさ**

```python
# 観測期間終了時点で「直近X日以内に購入」している割合
# アクティブユーザー率 = 直近30日以内購入者 / トライアル者
```

### 3.2 サイズ別定着率比較

- 各サイズでの定着率を算出
- 大サイズユーザーの長期継続率を評価

**期待される結果:**

- 小サイズ: 初回リピート率高いが、1回で離脱
- 大サイズ: 初回リピート遅いが、継続購入（定着）率高い

---

## 📊 Phase 4: Share of Wallet Analysis（財布のシェア）

### 4.1 カテゴリ内SOW測定

**測定指標:**

```python
SOW = トライアル製品への支出額 / カテゴリ全体への支出額 × 100

# 期間別比較
- トライアル前3ヶ月のSOW
- トライアル後3ヶ月のSOW
- トライアル後6ヶ月のSOW（可能な場合）
```

### 4.2 サイズ別SOW比較

**分析内容:**

- トライアル時サイズごとの「SOW増加幅」を比較
- トライアル前 vs トライアル後のSOW変化

**仮説:**

- 大サイズトライアル者: SOW増加幅が大きい（カテゴリ支出の大部分を占める）
- 小サイズトライアル者: SOW増加小（他製品と併用）

### 4.3 製品スイッチング分析

**測定:**

```python
# トライアル前の主要購入製品
# トライアル後の製品ポートフォリオ変化
スイッチング率 = 完全に製品を切り替えた人の割合
併用率 = トライアル製品と他製品を併用する人の割合
```

---

## 📊 Phase 5: Customer Lifetime Value (CLV) Estimation

### 5.1 サイズ別CLV計算

**計算式:**

```python
CLV = (平均購入回数 × 平均購入単価) × 観測期間内

# サイズ別で比較
詰替ﾃﾗｼﾞｬﾝﾎﾞトライアル者: 2.1回 × ¥1,200 = ¥2,520
本体通常トライアル者: 3.5回 × ¥480 = ¥1,680
```

### 5.2 容量ベースの価値評価

**測定:**

```python
# 単価ではなく「購入容量」で評価
CLV(容量) = 観測期間内の総購入容量(g or ml)

大サイズユーザー: 平均 5,200g購入
小サイズユーザー: 平均 2,800g購入
```

本体通常 → 詰替ﾒｶﾞｼﾞｬﾝﾎﾞ (アップグレード: 25%)
